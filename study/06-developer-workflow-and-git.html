1. The 3 Stages of Git

Git is a local version control time machine. Every milestone is saved as a Commit: 

[ Working Directory ] ──► git add . ──► [ Staging Area ] ──► git commit ──► [ Local Git History ]
(Your files in VS Code)                  (Box packed)                       (Snapshot saved)
                                                                                   │
                                                                          git push origin main
                                                                                   ▼
                                                                           [ GitHub Cloud ]

2. Environment Variables & Secrets (.env)

🚨 Golden Rule of Software Engineering
Never commit secret database passwords or private API tokens to GitHub!
Automated crawler bots scan public GitHub repositories every second. If an exposed password is found, hackers can access or destroy your database.

We store secrets in .env and list .env inside our .gitignore file so Git always ignores it. We provide a safe template called .env.example for teammates.

4. Common Beginner Troubleshooting Tips

  • PowerShell execution policy blocks npm:
    Run npm using & "C:\Program Files\nodejs\npm.cmd" instead of npm.
  • Port 5000 already in use:
    A previous Node server is still running in the background. Stop it with: Get-Process node -ErrorAction SilentlyContinue | Stop-Process -Force
  • PostgreSQL UUID error (22P02):
    PostgreSQL only allows hex characters (0-9, a-f) in UUID fields. Avoid non-hex letters like u, s, l.
