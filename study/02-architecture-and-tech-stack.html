3. The Tech Stack Explained for Beginners

TypeScript (.ts & .tsx)

JavaScript with strict type safety. It ensures variables hold the types you expect (strings, numbers, objects).

💡 Real-World Analogy: Plain JavaScript is like writing an essay without spellcheck. TypeScript is a live grammar and spelling checker that catches bugs before you run the code.
React 19 (aroom-web/)

A library for building user interfaces using reusable building blocks called Components.

💡 Real-World Analogy: Like LEGO bricks. Instead of building one huge web page, you build a <ListingCard /> brick, a <TrustBadge /> brick, and assemble them.
Vite

A modern frontend build tool and local dev server. It recompiles changed files in milliseconds using Hot Module Replacement (HMR).

Tailwind CSS

A utility-first CSS framework. Instead of writing custom CSS rules in a separate file, you style directly inside JSX elements (e.g. bg-green-600 text-white rounded-lg).

Node.js & Express (backend/)

Node.js runs JavaScript on the server. Express is the web framework that listens on Port 5000 and responds to API requests.

PostgreSQL & Supabase (supabase/)

PostgreSQL is a world-class relational database. Supabase provides cloud hosting, authentication, database storage, and a dashboard.
